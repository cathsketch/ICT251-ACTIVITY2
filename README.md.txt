## Project Overview
This repository contains the interactive personal portfolio developed by Catherine Lengwe for ICT251 Web Technologies Activity 3.

## Implemented JavaScript Features
1. **Contact Form Validation & Preview (Compulsory):** Performs client-side validation for non-empty input and valid email syntax, rendering a dynamic preview upon validation.
2. **Dark/Light Theme Toggle:** Allows visitors to switch seamlessly between dark and light viewing modes.
3. **Mobile Navigation Menu:** Provides an expandable/collapsible toggle menu optimized for mobile screens.
4. **Photo Gallery Viewer:** Interactive photo viewer with Previous and Next control buttons.
5. **Project Search & Filter:** Dynamic input filter that searches projects and skills with a reset function.
6. **Study Hours Calculator:** Accepts study inputs and outputs total planned weekly study time.
